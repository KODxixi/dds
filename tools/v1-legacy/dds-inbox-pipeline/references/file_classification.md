# 建筑行业全流程文档分类规则

为了支持建筑行业全生命周期（全流程）的多样化项目，DDS 资料准备系统采用**双维矩阵分类法**来识别和分类 inbox 中的文档。

---

## 一、双维矩阵分类体系

在扫描阶段，Agent 需识别文档的两个核心维度：**项目生命周期阶段** 与 **专业学科门类**。

### 1. 横轴：项目生命周期阶段 (Lifecycle Stages)

| 阶段代码 | 阶段名称 | 阶段定义与主要输入文件特征 |
|:---|:---|:---|
| `STAGE_FEASIBILITY` | **前期策划与可行性研究** | 投资估算表、选址报告、可研报告、拿地条件、竞品调研 |
| `STAGE_CONCEPT_SCHEME`| **方案/概念设计** | 方案文本（PPT/PDF）、效果图、日照分析报告、设计说明书 |
| `STAGE_PRELIMINARY` | **初步设计** | 初步设计图纸说明、工程概算书、消防专题报告、专项技术方案 |
| `STAGE_CONSTRUCTION_DWG`| **施工图设计** | 施工图说明、大样详图、施工图审查意见、各专业计算书 |
| `STAGE_TENDERING` | **招投标与采购** | 招标文件、招标控制价、工程量清单 (BOQ)、材料采购限价表 |
| `STAGE_CONSTRUCTION` | **施工建设与建造** | 施工组织设计、设计变更联系单、现场施工照片、BIM 协调记录 |
| `STAGE_HANDOVER` | **竣工验收与交付** | 竣工图纸、验收报告、消防验收批复、交付标准说明书 |
| `STAGE_OPERATION_MAINT`| **运营维护与资产管理** | 设备运行维护手册、物业管理白皮书、BIM 运维数据、能耗报告 |

### 2. 纵轴：专业学科门类 (Professional Disciplines)

| 专业代码 | 专业名称 | 包含内容与常见关键词 |
|:---|:---|:---|
| `DISC_PLANNING` | **规划/总图** | 控规、红线、退界、绿化率、指标表、总平面图 |
| `DISC_ARCH` | **建筑** | 户型、立面、剖面、日照、防火分区、外立面材质 |
| `DISC_STR` | **结构** | 钢筋、混凝土、荷载、抗震、剪力墙、地基基础 |
| `DISC_MEP` | **机电/设备** | 给排水、消火栓、暖通、新风、配电、强电、弱电、智能化 |
| `DISC_COST` | **概预算/成本** | 概算、预算、清单、综合单价、利润率、造价指标 |
| `DISC_BIM` | **BIM/数字孪生** | Revit 模型、IFC 格式、碰撞检测、数字化运维、设备台账 |
| `DISC_CIVIL` | **市政/岩土** | 基坑围护、道路管网、土石方、地质勘察报告 |

## 二、文件分类决策矩阵 (Matrix Classifier)

Agent 应根据文件的文件扩展名、大小及文件名包含的关键词，按下表组合进行匹配：

| 文件特征 (关键词) | 推荐生命周期阶段 | 推荐专业学科 | 推荐分类名 |
|:---|:---|:---|:---|
| 含有 "估算/测算/可研/地块/拿地" | `STAGE_FEASIBILITY` | `DISC_COST` / `DISC_PLANNING` | `FEAS_COST_MODEL` |
| 含有 "方案/汇报/概念/汇报文本" 且 PDF/PPT | `STAGE_CONCEPT_SCHEME` | `DISC_ARCH` | `CONCEPT_PRESENTATION` |
| 含有 "初步设计/概算" | `STAGE_PRELIMINARY` | `DISC_COST` | `PRELIM_BUDGET` |
| 含有 "图纸说明/施工图/大样" | `STAGE_CONSTRUCTION_DWG`| `DISC_ARCH` / `DISC_STR` | `CONSTR_DRAWING` |
| 含有 "图审/审查意见" | `STAGE_CONSTRUCTION_DWG`| `DISC_ARCH` | `CONSTR_REVIEW` |
| 含有 "工程量清单/清单/控制价/招标文件" | `STAGE_TENDERING` | `DISC_COST` | `TENDER_BOQ` |
| 含有 "设计变更/联系单/施工方案" | `STAGE_CONSTRUCTION` | `DISC_ARCH` / `DISC_STR` | `CONST_CHANGE` |
| 含有 "竣工图/验收" | `STAGE_HANDOVER` | `DISC_ARCH` | `HANDOVER_DOC` |
| 含有 "运行维护/运维/设备手册" | `STAGE_OPERATION_MAINT`| `DISC_BIM` / `DISC_MEP` | `OPS_MANUAL` |

## 三、各阶段解析策略与深度要求

### 1. 前期策划与可行性研究 (`STAGE_FEASIBILITY`)
*   **重点提取**：投资回报率 (IRR)、静态投资回收期、楼面地价、拆迁补偿单价、项目总投资。
*   **解析方法**：对 Excel 测算表使用 openpyxl 提取所有 Sheet 关联数据；对文本类可研进行 PDF 结构化文字解析。
*   **校验指标**：对比规划面积与测算面积的误差，校验造价指标是否超出同地区标准包络。

### 2. 方案/概念设计 (`STAGE_CONCEPT_SCHEME`)
*   **重点提取**：总体规划指标（容积率、密度、绿地率）、日照时长、建筑立面材质、建筑风格、户型配比配平。
*   **解析方法**：将大型 PDF/PPT 分割并导出为 ≤1MB 的 PNG 序列，送入 VLM (视觉语言模型) 识读效果图、手绘草图和总图指标。
*   **校验指标**：交叉校验日照分析报告中的最不利点日照时间是否符合当地技术规范要求。

### 3. 初步设计阶段 (`STAGE_PRELIMINARY`)
*   **重点提取**：主要技术设备参数、基础选型、消防分区、主要结构荷载等级、主要机电系统参数。
*   **解析方法**：调用 pdfplumber 提取初步设计图纸及说明的文字，重点抓取“主要技术经济指标表”。
*   **校验指标**：比对初步设计概算与前期可研估算，若概算超估算 10% 则触发橙色超支预警。

### 4. 施工图设计阶段 (`STAGE_CONSTRUCTION_DWG`)
*   **重点提取**：图审缺陷、强条违反记录、细部构造节点材质、混凝土强度等级、钢筋配筋率。
*   **解析方法**：结构化解析图审意见（DOCX）中的“违反强条条文”及“修改意见表”，将意见分类归档。
*   **校验指标**：比对图纸中的各种材质是否符合方案设计阶段确定的立面风格导向。

### 5. 招投标与采购阶段 (`STAGE_TENDERING`)
*   **重点提取**：工程量清单项目编码、项目特征描述、暂估价项目、主材及设备单价限价。
*   **解析方法**：将工程量清单（Excel 或 PDF 格式的 BOQ）转换为结构化数据表，按分部分项工程归类。
*   **校验指标**：将主材限价与材料库历史价格数据库比对，识别“高价离群值”。

### 6. 施工建设阶段 (`STAGE_CONSTRUCTION`)
*   **重点提取**：设计变更原因（设计疏忽/业主变更/现场条件不符）、变更估算造价、现场照片配准。
*   **解析方法**：从变更单中抽取变更原因关键词 and 涉及的估算增减造价。
*   **校验指标**：统计累计设计变更造价，计算是否超出合同预算中的暂列金额或预备费。

### 7. 竣工验收阶段 (`STAGE_HANDOVER`)
*   **重点提取**：实测实量偏离值、竣工验收意见、消防与人防合格证批复文号、实测竣工面积。
*   **解析方法**：解析验收报告和批文扫描件，重点获取政府批复的竣工备案面积和容积率。
*   **校验指标**：实测竣工面积与规划报建面积对比，差异超过 ±3‰ 时需要报警提示。

### 8. 运营维护阶段 (`STAGE_OPERATION_MAINT`)
*   **重点提取**：设备台账、维护周期、易损件清单、能耗基准、关键资产价值。
*   **解析方法**：从设备手册中抽取维护周期表；将设备台账数据格式化，用于与 GIS/BIM 数字孪生系统挂接。
*   **校验指标**：匹配设备台账与初步设计阶段的设备清单，记录缺失的随机设备运维文档。
