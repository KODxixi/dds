# 调研资料权威性索引

本目录保存研究输入和历史调研，不自动构成 DDS 的生产证据。进入报告的数据必须转换为可追溯的 `EvidenceRecord`，并通过来源、时间、地域、单位和证据类型校验。

## 权威性标签

- **authoritative**：已核验的一手官方来源；仍需记录基准日、适用地域和快照哈希。
- **verified-secondary**：已核验的二手资料，可用于背景或交叉验证，不替代一手事实。
- **exploratory**：探索性调研或方案线索；不得直接生成客户可见数值。
- **historical**：旧方案背景，仅用于理解迁移原因或生成回归用例。
- **superseded**：核心假设已被 V2 契约替代，不得作为当前方法依据。

## 使用规则

1. 调研文档只能生成数据需求、候选来源或补证动作。
2. 任何数字进入业务引擎前，必须具备来源引用或来源哈希、统计期、地域、单位、方法和适用限制。
3. 用户提供的文本默认是 `social_observation`，不能因被写入本目录而升级为 `observed_fact`。
4. 来源冲突或陈旧时保留 `conflict` / `stale`，不得选择更“好看”的数值覆盖。
5. 重新核验后，应新增独立来源清单或快照，不直接把历史文档标签改为 `authoritative`。
