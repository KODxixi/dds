## 0. 背景与目标

DDS v2（当前 v2.1.0，M0–M6 已完成，145 tests 全绿）已具备 `agents/`（Agent 化）、`engines/`（确定性引擎）、`services/`（编排）、`data/adapters/`（证据前处理适配器）与 `evidence_store`/`contracts`/`analysis_profile` 完整体系。

本 Spec 目标：在不破坏任何引擎、Agent、适配器与既有测试的前提下，把 DDS 的数据来源从「单一本地磁盘库」升级为**多数据源可插拔**架构，并将**中指数据（crowd-research / 商业授权数据）仅作为一个可选项**挂接——授权到期或断线时，系统自动回退本地/用户源，核心研判永不中断。

### 设计原则（呼应既有决策）

1. **数据源 = 可插拔实现，不是代码里写死**（D1：数据层与引擎层解耦）。
2. **中指仅作可选源**：默认关闭，显式配置 + 授权健康时参与路由；断供自动跳过，绝不崩平台。
3. **单一路由出口**：消费方（engine/adapter/Agent/research pipeline）只见到 `CompetitorQuery → QueryResult` 一个契约，多源合并在其之下的 Router 内部完成。
4. **证据溯源不丢**：任何源的结果都携带 `DatasetAsset(authority + source_hash)` 与 `query_signature`，报告如实标注「中指数据·获取日」，守住既有「数据以中指为准」红线。
5. **离线兜底**：中药数据拉取后落为 `parquet` 快照（带 source_hash），授权失效后仍可读已授权期间留存的合法缓存。
6. **合规隔离**：对外再分发时，路由不透传中指 token；新增 `data_redistributable` 标记，防止商业数据被二次转售。

## 3. 新增契约：`IDataSource`（`src/dds/data/sources/base.py`）

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import Any, Mapping
from src.dds.data.repository import CompetitorQuery, QueryResult


class DataUnavailableError(RuntimeError):
    """数据源当前不可用（未配置/未授权/断线）。"""


@dataclass(frozen=True)
class SourceInfo:
    name: str                 # "local" | "zhongzhi" | "user"
    tier: str                 # "primary" | "fallback" | "user"
    authority: str            # 权威声明，如"中指数据"/"本地快照"
    licensed: bool            # 是否依赖商业授权
    licensed_ok: bool         # 当前授权是否有效


class IDataSource(ABC):
    @property
    @abstractmethod
    def info(self) -> SourceInfo: ...

    @abstractmethod
    def query_new_homes(self, q: CompetitorQuery) -> QueryResult: ...
    @abstractmethod
    def query_transactions(self, q: Any) -> QueryResult: ...
    @abstractmethod
    def query_land(self, q: Any) -> QueryResult: ...
    @abstractmethod
    def query_macro(self, q: Any) -> QueryResult: ...

    def available(self) -> bool:
        """已配置且可达（未配置/授权失效返回 False，不抛错）。"""
        return True

    def health(self) -> dict:
        """延迟/错误率/最近命中时间。"""
        return {}

    def require_license(self) -> bool:
        return self.info().licensed
```

> 四种 `query_*` 全部复用既有 `CompetitorQuery → QueryResult` 契约 → **引擎与 adapter 零改动**。

## 4. 三个实现

### 4.1 `LocalSource`（`src/dds/data/sources/local.py`）— 第一兜底源
把现有 `DatasetRepository` 薄包装，登记为回退源：

```python
class LocalSource(IDataSource):
    tier = "fallback"
    def __init__(self, repo: DatasetRepository | None = None):
        self._repo = repo or DatasetRepository()
    @property
    def info(self): return SourceInfo("local","fallback","本地快照",False,True)
    def query_new_homes(self, q): return self._repo.query_competitors(q)
    # transactions/land/macro 同理转发
```

### 4.2 `ZhongzhiSource`（`src/dds/data/sources/zhongzhi.py`）— 可选优先源

```python
class ZhongzhiSource(IDataSource):
    tier = "primary"
    def __init__(self, *, base_url: str, token: str | None, cache_dir: Path):
        # token 为空 → licensed_ok=False → available()=False
        self._token = token
        self._ok = bool(token)
        self._cache = EvidenceStore(cache_dir)

    @property
    def info(self): return SourceInfo("zhongzhi","primary","中指数据",True,self._ok)

    def available(self):
        return self._ok and self._http_health()

    def query_new_homes(self, q):
        if not self.available():
            raise DataUnavailableError("中指授权不可用")
        # 1) 先查本地缓存（已授权期间留存的合法快照）
        cached = self._cache.lookup(q)
        if cached: return cached
        # 2) 调线上接口（对应 project_statistics/project_detail 等能力）
        payload = self._call_api(q)
        # 3) 落盘缓存 + Authority 标注，返回 QueryResult
        return self._to_query_result(payload, authority="中指数据")

    def require_license(self): return True
```

**授权/断供语义**：
- `licensed_ok` 由 token / 授权对象驱动；失效即 `available()=False` → Router **跳过**，换本地/用户源。
- 每次线上拉取落盘为 parquet 快照 + source_hash，`authority` 标「中指数据·获取日」。
- 缓存可设 TTL：线上数据新鲜度优先时，缓存只作断供/离线兜底；报告仍按 acquisition date 标注时效。

### 4.3 `UserSource`（`src/dds/data/sources/user.py`）— 用户材料源
包装既有 `user_materials.py` 适配器，接受用户上传 Excel/CSV/材料，`tier="user"，authority="用户材料"`。

## 5. Router：`DataSourceRouter`（`src/dds/data/router.py`）— 核心

```python
class DataSourceRouter:
    """把注册的多个 IDataSource 编排成一个逻辑源。"""
    def __init__(self, sources: list[IDataSource],
                 strategy: Literal["priority","liveonly","userfirst"]="priority"):
        self._sources = sources          # 顺序即优先级

    def query(self, kind: str, q: CompetitorQuery) -> QueryResult:
        for src in self._sources:
            if not src.available():
                continue                 # 授权失效/未配置 → 静默跳过
            try:
                result = getattr(src, f"query_{kind}")(q)
                return result            # 命中即返回，附 authority
            except (DataUnavailableError, Exception) as exc:
                logger.warning("source %s failed: %s", src.info.name, exc)
                continue                 # 失败回退下一源
        raise DataUnavailableError(f"所有数据源均不可用: {kind}")

    def query_merge(self, kind, q):       # 可选：多源交叉校验
        ...
```

**回退语义（最稳路径）**：
```
configured 中 index = zhongzhi(若 licensed_ok 且健康) → 用中指（最新鲜）
否则 → local（现有磁盘快照，永健在）
否则 → user（用户材料）
全部缺失 → DataUnavailableError → gap 显式暴露（既有 fallback/gap 机制处理）
```

## 6. 通道 B：`DataFetcher` provider 多源编排

`fetcher.py` 已支持按注入顺序短路 + 异常 continue。多源化只需调整 providers 注册顺序：

```python
providers = {
    "zhongzhi": zhongzhi_fetch_provider,   # 需授权；失败自动 continue
    "local":    local_fetch_provider,
    "user":     user_material_provider,
}
fetcher = DataFetcher(providers=providers)
```
授权开关与 provider 注册绑定：`zhongzhi_fetch_provider` 内部检查 `licensed_ok`，失效直接返回 `(None,None)`（视作缺失），由 fetcher 短路到下一 provider。

## 10. 风险与阻塞

- **数据/授权合规**：中指数据对外 SaaS 再分发需单独确认授权条款；本 Spec 通过「中值可选 + 隔离 token + redistributable 标记」降低风险，但商务合规须由法务/商务单独核验。
- **缓存一致性**：中值数据时效性与本地快照可能不一致，报告 must 标注获取日与源。
- **未提交改动**：工作区有大量未提交迁移（含 data adapters、API 等），实现前先确认归属与版本冻结，不得 reset/clean。
- **投决级权限**：本 Spec 只解决数据接入，不改变 `delivery_ready` 与 decision_scope 门槛（投资/定价/拿地仍锁闭）。
